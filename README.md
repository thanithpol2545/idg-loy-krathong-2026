# IDG Loy Krathong 2026 🏮

> **กระทงสร้างสรรค์ เทพีแห่งนวัตกรรม | Interactive Slide & Float Krathong with Data Storage**

เว็บไซต์จำลองเทศกาลลอยกระทงแบบ Interactive สไตล์งาน **IDG Loy Krathong 2026** สามารถพิมพ์คำอธิษฐานและ **สไลด์/ลากกระทงไปลอยบนสายน้ำ** ได้จริงแบบเรียลไทม์ พร้อม **ระบบบันทึกข้อมูล (Data Storage)** ครบวงจร

---

## ✨ ไฮไลท์ฟีเจอร์ (Features)

- 💾 **ระบบบันทึกข้อมูล (Persistent Data Storage):** 
  - บันทึกกระทงและคำอธิษฐานลงใน `localStorage` อัตโนมัติทุกครั้งที่ปล่อยกระทง
  - รีเฟรชหน้าเว็บหรือปิดเบราว์เซอร์แล้วเปิดใหม่ ข้อมูลกระทงและคำอธิษฐานยังคงลอยอยู่ครบถ้วน
  - ซิงค์ข้อมูลข้ามแท็บแบบเรียลไทม์ด้วย `BroadcastChannel` และ `storage event`
- 📜 **สมุดบันทึกคำอธิษฐาน (Wish History Log):**
  - เปิดดูรายการคำอธิษฐานทั้งหมดที่เคยปล่อยลอย
  - แสดงไอคอนกระทง, ข้อความคำอธิษฐาน, วันที่-เวลาอย่างละเอียด (เช่น `24 พ.ย. 2569 เวลา 09:30 น.`), และสถานะนิรนาม
- 📥 **ส่งออกข้อมูล (Export Data):**
  - ดาวน์โหลดเป็นไฟล์ **CSV** สำหรับเปิดดูและสรุปผลใน Microsoft Excel / Google Sheets
  - ดาวน์โหลดเป็นไฟล์สำรอง **JSON**
  - ปุ่มรีเซ็ตล้างข้อมูลเมื่อต้องการเริ่มต้นใหม่
- 🌊 **สไลด์กระทงไปลอย (Slide to Float):** ลากกระทงจากแท่นด้านล่างสไลด์ขึ้นไปปล่อยลอยบนสายน้ำ หรือแตะที่ผิวน้ำเพื่อปล่อยกระทง
- ✍️ **คำอธิษฐานนิรนาม & เวลาลอย:** พิมพ์คำอธิษฐานแล้วจะปรากฏเป็นป้ายข้อความลอยอยู่เหนือกกระทงพร้อมเวลาที่ลอย โดย **ไม่แสดงชื่อผู้พิมพ์** เพื่อความเป็นส่วนตัว (Anonymous)
- 🪷 **เลือกกระทงได้ 4 สไตล์:**
  - 🪷 ดอกบัวหลวงสีชมพู (Classic Lotus)
  - 🌸 ซากุระมงคล (Cherry Blossom)
  - 🌺 ชบาดอกแดงสดใส (Hibiscus)
  - 🍃 ใบตองรักษ์โลก (Eco Banana Leaf)
- 🌙 **บรรยากาศแสงจันทร์ริมน้ำแบบไทย:** ดวงจันทร์เต็มดวง, แสงสะท้อนบนผิวน้ำ, โคมลอยลอยขึ้นสู่ฟ้า, หิ่งห้อยบินระยิบระยับ, เงาวัดและเจดีย์
- 🎵 **เสียงคลื่นน้ำและกระดิ่ง (Web Audio API):** เล่นเอฟเฟกต์เสียงน้ำและกระดิ่งเบาๆ ตอนปล่อยกระทงโดยไม่ต้องโหลดไฟล์ภายนอก
- 🔍 **แตะดูกระทง:** แตะที่กระทงใดก็ได้บนสายน้ำเพื่อเปิดดูคำอธิษฐานเต็มๆ และเวลาที่ปล่อยลอย
- 📱 **รองรับทุกหน้าจอ:** มือถือ, แท็บเล็ต, และคอมพิวเตอร์ (Touch & Mouse friendly)

## 🚀 วิธีเปิดใช้งาน (Getting Started)

เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ได้ทันที ไม่จำเป็นต้องติดตั้งไลบรารีใดๆ (Zero Dependencies) หรือรันผ่าน local server:

```bash
# รัน local server ด้วย Python
python -m http.server 8080
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`
